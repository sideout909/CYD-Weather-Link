# WX Link icon

`wx-link-icon-v1.png` is the original transparent PNG for online profiles,
project pages and social uploads. Generated using the built-in image_gen tool
through the imagegen skill. It is not embedded in firmware or installed online.

## Generation prompt

Use case: logo-brand. Create one polished original icon-only logo for WX Link, an open-source amateur-radio weather station project connecting home weather sensors to weather-sharing networks. Single compact cohesive emblem: a bold, elegant weather cloud combined with a small warm yellow sun peeking above it and two clean cyan radio signal arcs integrated naturally into the cloud's right side, suggesting weather connected by radio. A distinctive interlocking negative-space detail can subtly suggest a link, but keep the silhouette simple and instantly readable at avatar/favicon size. Palette drawn from this project's display: deep midnight navy #080f1b for solid outlines and grounding, bright cyan #61d8ed and restrained sunny yellow #ffc16b. Flat graphic design with crisp vector-like edges, rounded consistent geometry, generous negative space, thick sturdy strokes and very limited detail. Square 1024x1024 composition, centered emblem filling roughly 80% of canvas with comfortable equal safe margins, suitable for GitHub avatar, social profile and stickers. True transparent background, clean alpha edges. No text, no initials, no lettering, no wordmark, no watermark, no mockup, no extra alternate logos, no gradients, no glossy 3D effects, no tiny circuitry.
